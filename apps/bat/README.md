# bat

Requires bat 0.26+ (pin: 0.26.1).

Manual copy: `config` → `$XDG_CONFIG_HOME/bat/config`. If XDG_CONFIG_HOME is unset, use `~/.config`.
Copy the listed files (or entire folder for Neovim) without needing this repository.

No plugins or downloads. Local one-off choices can use BAT_THEME/BAT_STYLE/BAT_PAGER or command arguments; bat does not load an invented config.local include.
