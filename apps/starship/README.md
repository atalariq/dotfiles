# starship

Requires Starship 1.26+ (pin: 1.26.0).

Manual copy: `starship.toml` → `$XDG_CONFIG_HOME/starship.toml`. If XDG_CONFIG_HOME is unset, use `~/.config`.
Copy the listed files (or entire folder for Neovim) without needing this repository.

Fish initializes Starship if it is installed. No special font is required by these settings, though enabled default Starship modules may use symbols. No downloads. There is no general TOML local include; use STARSHIP_CONFIG for a private alternative or edit the native file.
